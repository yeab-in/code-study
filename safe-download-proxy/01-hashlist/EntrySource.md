# EntrySource

원본: hashlist/domain/EntrySource.java (19feb87)

## 코드 읽기 전 생각
" EntrySource " 만 봤을 때 드는 생각
=> Entry가 처리를 기다리는 입력이라고 알고 있기 때문에 처리를 기다리고 있는 데이터들을 담아둔 파일인 것 같다.
==> Entry는 블랙/화이트리스트에 등록된 항목(BlacklistEntry 등)이었고, EntrySource는 블랙리스트 항목의 등록 방식을 나타내는 enum이었다.

- Source라는 단어는 뭘 뜻할까?
=> 사람이 읽을 수 있는 평문
==> 여기서는 출처를 의미한다. 항목이 어떤 방식이 등록되었는지 확인할 수 있다.

- 블랙/화이트리스트 항목의 출처를 구분하면 뭐가 좋을까?
=> 잘모르겠다.

- 값이 몇 개쯤 있고, 이름은 뭘까?
블랙리스트, 화이트리스트를 다뤄야하니까 값이 2개정도 있지 않을까 싶다.
==> 개수는 2개로 맞았지만 이유는 달랐다. 실제로는 MANUAL, IMPORT였다.

## 코드 읽은 후 생각

**Q. 어떤 값들이 들어 있나? (종류가 몇 개고 이름이 뭔가)**

A. 종류는 2가지로 관리자가 직접 등록하는 MANUAL, 일괄 등록하는 IMPORT가 있다.

**Q. 값마다 따로 들고 있는 정보가 있나? (이름 말고 다른 필드가 있는지)**

A. 없다.

**Q. 이 값이 DB에 어떻게 저장될 것 같나? (HashType, Severity 주석과 비교해서)**

A. 1:1로 대응되어 저장된다.

**Q. 블랙리스트와 화이트리스트 중 어디에 쓰이는 값인가? (코드나 주석에서 단서를 찾기)**

A. 블랙리스트에 쓰이는 값이다.

**Q. 이 값을 어디에서 쓰는지는 이 파일로 알 수 있나?**

A. 알 수 없다.
