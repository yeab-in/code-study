# code-study

내가 작성한 프로젝트 코드를 하루 한 파일씩 분석하고 정리하는 공부 기록.

## 프로젝트

| 프로젝트 | 공부 기간 |
|---|---|
| 프록시 기반 다운로드 파일 검사 서비스 | 2026-11-02 ~ 11-28 |

## 폴더 구조

```
프로젝트/단계/파일명.md + 파일명.java
```

## 글 쓰는 순서

1. 코드를 보기 전에 이 파일이 하는 일을 두세 줄로 먼저 적는다.
2. 코드를 읽고 한 줄씩 내 말로 설명한다.
3. 설명이 안 되는 부분은 "아직 모르는 것"으로 따로 적는다.
4. 조사해서 채우고 날짜를 남긴다.
5. 글 맨 위에 원본 파일 경로와 커밋 해시를 적는다.

## 참고

분석 대상 코드는 팀 프로젝트에서 내가 작성한 부분을 공부용으로 옮긴 사본이다. 원본은 각 프로젝트의 팀 레포에 있다.
